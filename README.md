## 🎯 ภาพรวม

Exam Formatter คือระบบอัตโนมัติที่แปลงไฟล์ข้อสอบจากครูอาจารย์ (PDF/DOCX) ให้เป็นรูปแบบมาตรฐานของโรงเรียน พร้อมใส่ Logo, จัดหน้า, และจัดระยะห่างตาม Grid System อย่างแม่นยำ

### 💡 ปัญหาที่แก้

| ❌ วิธีเดิม (Manual) | ✅ วิธีใหม่ (Automated) |
|---------------------|------------------------|
| ครูส่งไฟล์มาหลายรูปแบบ | แปลงเป็นรูปแบบมาตรฐานอัตโนมัติ |
| ต้องจัดหน้าทีละไฟล์ | จัดหน้าอัตโนมัติทั้ง 10,000 ไฟล์ |
| ใส่ Logo ด้วยมือทุกไฟล์ | ใส่ Logo อัตโนมัติ 5 จุด |
| ใช้เวลา 15-30 นาที/ไฟล์ | ใช้เวลา 2-3 วินาที/ไฟล์ |
| มีความผิดพลาดสูง | ความแม่นยำ 100% |
